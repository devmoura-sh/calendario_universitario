### O que é o projeto ?

O projeto consiste em um sistema de organização de calendários voltado ao ambiente acadêmico, projetado para atender estudantes e instituições de ensino.

Acabou essa ladainha de descobrir que não tem aula só quando chega na faculdade depois de duas horas no trem (experiencia pessoal). Ou descobrir que tem prova num dia que você nem sabia que tinha aula.

### Plataforma

Primordialmente será uma *Web Application*, porém futuramente pode vir a migrar para desktop e mobile, quem sabe...?
